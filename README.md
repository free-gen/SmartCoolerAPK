# Smart Cooler for Android

[![Latest Release](https://img.shields.io/github/v/release/free-gen/SmartCoolerAPK?label=Download%20APK&style=flat-square)](https://github.com/free-gen/SmartCoolerAPK/releases/latest/download/SmartCooler.apk)

A lightweight Android application for monitoring and controlling the **PS5 Smart Cooler** based on ESP32.

The app provides fullscreen access to the Smart Cooler web interface directly from your phone, without requiring a browser.

### Features

- Automatic device discovery over local Wi-Fi.
- Manual connection by IP address.
- Support for multiple Smart Cooler devices.
- Choice of web interface: Main UI, Main UI v2, or Web App.
- Automatic reconnection to saved devices.
- Update notifications via GitHub Releases.
- Optional diagnostic reporting.

### How it works

Connect your phone to the same Wi-Fi network as your Smart Cooler, open the app, and select your device. The web interface is loaded directly from the ESP32.

No cloud connection is required to control the device.
